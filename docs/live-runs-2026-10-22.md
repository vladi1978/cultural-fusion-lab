# Live runs of 2026-10-22: evidence summary

Two live runs of the full pipeline against the Qloo hackathon API and a hosted model, on one brief:
*"Design a bicycle ride and live jazz listening evening in Louisville, Kentucky"* (interest: cycling and jazz).

## What this is, and is not

- It is a **transcription** of the counters and server log lines shown on the founder's machine at the time, plus the on-screen panels. The raw terminal logs and screenshots are not stored in this repository.
- It does **not** show that Qloo improved concept quality. Both runs ended with the controlled-comparison verdict **"Qloo influence not demonstrated"**.
- It does show that the integration made real Qloo calls, that entities kept their provenance, and that the validation gates and the comparison behaved as designed, including refusing to claim influence.
- Authentic Qloo responses that anyone can inspect without keys are in `src/lib/qloo/fixtures/`; see the README section "How to verify Qloo integration without API keys".

## Reading these results honestly

- On this brief the base model already writes a strong jazz-and-ride concept without Qloo, and Qloo returned a single verified local place.
- Two runs on one brief with two generations per arm is a careful probe, not a statistical study.
- A system that reports "not demonstrated" and "zero grounded decisions" when that is the truth is the intended behavior.
